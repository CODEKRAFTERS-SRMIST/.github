## 🔥 About Us

**CodeKrafters** is not just another college club — we are a **student-led developer collective** powering **7 specialized domains**, shipping **real-world software**, winning **national hackathons**, and fostering **engineering excellence** at SRM Ramapuram.

We organize bootcamps, compete at national-level events like ETH India, DevsHouse & Aptos Hackathon, contribute to open source, and engineer impactful digital solutions — from Web3 smart contracts to full-stack applications.

## 🤝 Contribution Workflow

We welcome contributions from all members and the open-source community!

```
1. Fork & Branch     →  git checkout -b feature/amazing-feature
2. Commit Changes    →  git commit -m "feat: add user auth"
3. Push              →  git push origin feature/amazing-feature
4. Open a PR         →  Ensure checks pass, link related issues, request review
```

**Conventions:**
- Conventional commits (`feat:`, `fix:`, `docs:`, `chore:`)
- PR descriptions must link related issues
- All PRs require at least one maintainer review
